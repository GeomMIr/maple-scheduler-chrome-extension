# Maple Scheduler

메이플스토리 캐릭터의 일일·주간 스케줄러 진행 상황을 확인하는 비공식 Chrome 확장 프로그램입니다. 사용자가 게임 내 스케줄러에 등록한 항목을 불러오며, 여러 API 계정과 월드 사이를 전환할 수 있습니다.

## 주요 기능

- API 키에 연결된 캐릭터 목록을 불러와 선택한 캐릭터만 관리
- 일일 퀘스트, 주간·월간 보스, 길드 콘텐츠 표시
- 일일 보스는 숨기고, 몬스터파크는 월드별 `완료 횟수/14`로 표시
- 점수형 콘텐츠(예: 길드 지하수로)는 점수가 있으면 완료로 표시
- 마감 기간의 미완료 항목 강조: 일일 퀘스트·몬스터파크는 매일 22시 이후, 주간 보스·길드는 수요일, 월간 보스는 월말 4일

## 설치 및 시작

1. [넥슨 Open API 포털](https://openapi.nexon.com/ko/)에서 메이플스토리 API 키를 발급받습니다.
2. 이 저장소를 내려받거나 `Code` → `Download ZIP`으로 받은 뒤 압축을 풉니다.
3. Chrome 주소창에 `chrome://extensions`를 입력합니다.
4. **개발자 모드**를 켜고 **압축해제된 확장 프로그램을 로드합니다**를 선택합니다.
5. 압축을 푼 `maple-scheduler-chrome-extension` 폴더를 선택합니다.
6. 확장 프로그램의 **설정**에서 API 키를 등록하고 관리할 캐릭터를 선택합니다.

코드를 수정한 뒤에는 `chrome://extensions`에서 확장 프로그램의 새로고침 버튼을 누르면 변경 사항이 적용됩니다.

## API 키와 개인정보

- 본인의 넥슨 Open API 키만 사용하세요. API 키는 브라우저의 로컬 저장소에 암호화되어 저장됩니다.
- 암호화 키도 같은 브라우저 프로필에 저장되므로, 강한 비밀번호 관리자와 같은 보호를 제공하지는 않습니다. PC 계정과 브라우저 프로필을 안전하게 관리하세요.
- 이 확장 프로그램은 별도 서버로 API 키나 캐릭터 데이터를 전송하지 않습니다. 데이터 조회는 사용자의 브라우저에서 넥슨 Open API로 직접 요청합니다.
- API 키를 이 저장소나 공개된 이슈·화면 캡처에 올리지 마세요.

## 안내

이 프로젝트는 개인 제작 비공식 도구이며 넥슨 또는 메이플스토리와 관련이 없습니다. API 응답 및 게임 업데이트에 따라 표시 내용이 달라지거나 일부 데이터가 제공되지 않을 수 있습니다.
